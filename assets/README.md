# 素材の置き場所

**このフォルダの中身は Git にコミットされません**（`.gitignore` 済み）。
本人の顔・声を含む素材や、大きなバイナリを共有リポジトリに載せないためです。

**制作担当のローカルPCと、共有ドライブ（社内）の両方に同じ構成で置いてください。**

---

## フォルダ構成

```
assets/
├── opening/          #1 オープニング動画の素材
│   ├── ref/          ★参照画像（生成の一貫性を保つための基準）
│   ├── gen/          生成された動画（未編集）
│   └── overlay/      爆発・お札のオーバーレイ素材
├── avatar/           #2〜#4 のアバター背景（AVATAR_LOOK.md §3）
├── person/           ★8/20に撮影した本人素材（最も取扱注意）
└── export/           完成した書き出し（動画7本）
```
