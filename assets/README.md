# 素材の置き場所

**このフォルダの中身は Git にコミットされません**（`.gitignore` 済み）。
本人の顔・声を含む素材や、大きなバイナリを共有リポジトリに載せないためです。

**制作担当のローカルPCと、共有ドライブ（社内）の両方に同じ構成で置いてください。**

---

## フォルダ構成

```
assets/
├── opening/          #1 オープニング動画の素材
│   ├── ref/          ★参照画像（生成の一貫性を保つための基準）
│   ├── gen/          生成された動画（未編集）
│   └── overlay/      爆発・光の粒子のオーバーレイ素材
├── music/            ★楽曲（権利フリー／生成音源・OPENING_VIDEO.md §4）
├── avatar/           #2〜#4 のアバター背景（AVATAR_LOOK.md §3）
├── person/           ★8/20に撮影した本人素材（最も取扱注意）
└── export/           完成した書き出し（動画7本）
```

## `opening/ref/` ── 参照画像

生成の一貫性を保つ基準です。**これがブレると全カットがブレます。**

| ファイル名 | 中身 | 使う場面 | 状態 |
|---|---|---|---|
| `image2_stage.png` | 場所の基準（暗いステージ・無人） | GEN-2 | |
| `image1_silhouette.png` | 人物の基準（逆光シルエット） | GEN-2 | |
| **`walk_frame001.png`** | ★**歩きの1フレーム目** | **GEN-1** | **取得済み** |
| **`walk_frameLast.png`** | ★**歩きの最終フレーム**（到達して止まった瞬間） | **GEN-5・GEN-3a/3b** | |
| `person_front.png` | 本人の正面写真（顔の基準） | GEN-3 | 合意取得済み |

> 🚨 **歩きの「両端のフレーム」が、この構成の要です。**
>
> | | 参照する生成 | 役割 |
> |---|---|---|
> | `walk_frame001.png`（1フレーム目） | **GEN-1**（シルエット） | シルエットの終わりと同ポジで繋ぐ |
> | `walk_frameLast.png`（最終フレーム） | **GEN-5**（爆発→真っ白） | 爆発の瞬間に人物が飛ばないようにする |
> | `walk_frameLast.png`（最終フレーム） | **GEN-3a/3b**（正体判明・キメ） | 構図と光をCUT05から引き継ぐ |
>
> **前後のカットは、必ず隣のカットの端フレームを参照して作ります。**
> これをやらないと、繋ぎ目で人物の位置と大きさが飛びます。
> 手順は [`../docs/OPENING_VIDEO.md` §3-0-2](../docs/OPENING_VIDEO.md)。
>
> **消さないでください。** 引き直しのたびに必要になります。

後から「前のほうが良かった」となることがよくあります。
