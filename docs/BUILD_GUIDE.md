### 3-5　オープニング動画を作る 【制作】

→ **専用シートを用意しました：[`OPENING_VIDEO.md`](OPENING_VIDEO.md)**
　（36.18秒のシンクロシート・制作手順・当日の運用・#2への繋ぎ方）
→ **絵コンテ：[`storyboard.html`](storyboard.html)**（ブラウザで開く／印刷可）

> ✔ **秒数は 2026/8/10 に音源を解析して確定済み**です。テンポ 137.81 BPM、1小節 1.7415秒。
> **すべてのカット切り替えが小節線に乗っています。**推測で秒数を動かさないでください。

要点だけ再掲します。

- **全尺 36.18秒**。**動画は完全に無音**で書き出す（楽曲は会場PAから）
- **0–29.211秒は本人素材が不要**なので、合意前（〜8/18）に先行制作できる
  - **0.000–3.088秒：黒み**（音源の頭 1.570秒はファイル自体が無音）

    → **逆光で顔を飛ばす**ので本人素材が要らない
  - **23.986 / 25.728 / 27.470秒：カウントダウン 3・2・1**（1数字＝1小節＝1.7415秒）
  - **29.211秒：立ち止まる＋背後で大爆発＋お札が舞う**
