# 構築手順書（ステップバイステップ版）

**本番の21日前から当日までに、何を・どの順で・誰が作るか**を1手ずつ書いた手順書です。
上から順に実行すれば完成します。

- 当日の進行は [`MC_SCRIPT.md`](MC_SCRIPT.md)
- 外部サービスの画面操作は [`SERVICE_SETUP.md`](SERVICE_SETUP.md)
- アプリの公開は [`DEPLOY_GUIDE.md`](DEPLOY_GUIDE.md)

**各ステップの見方**：`【担当】所要時間` ／ 末尾の **✅** が「これができたら次へ」の判定基準

---

## 作るものの全体像

```
┌─ 動画 7本 ────────────────────────┐
│ 01_opening.mp4   #1 オープニング   │ ← deevid.ai（P3）
│ 02_greeting.mp4  #2 AI挨拶        │ ← HeyGen（P3）
│ 03〜07_qN_A.mp4  #3 クイズ5本      │ ← HeyGen（P3）
│ 08_loop.mp4      #4 ループ用       │ ← HeyGen（P3）
└──────────────────────────────────┘
┌─ 音声 ────────────────────────────┐
│ 想定質問5問の音声（キャッシュ）      │ ← ElevenLabs＋卓（P5）
└──────────────────────────────────┘
┌─ Webアプリ ───────────────────────┐
│ 配布用（QR）／オペレーター卓        │ ← Cloud Run（P4）
└──────────────────────────────────┘
┌─ 紙 ──────────────────────────────┐
│ 設問と正解／想定質問と回答／再生順   │ ← P6
└──────────────────────────────────┘
```

**依存関係（ここだけ注意）**

```
本人の同意 ──→ HeyGenアバター ──┬─→ 動画6本
            └→ ElevenLabs音声 ─┘        ↑
「他者から見える佐々木さん」→ AI調整 ─────┘（原稿の質が決まる）
```

**同意が最上流**です。ここが遅れると全部が遅れます。

# Phase 2　AIの調整（D-14 〜 D-10）

ここでAIの回答品質を決めます。**この工程を飛ばすと、クイズが一瞬で見破られます。**

### 2-1　集めたエピソードをAIに教える 【制作】60分

**編集するファイル：`data/persona.md`**

1-5 で集めた内容を、次の2つの節に追記します。

**① 「話し方・口調」の節に追記**
```markdown
- 一人称は「私」。落ち着いた丁寧語（です・ます調）で話す
（↓ここに追記）
- 「〜だと思うんですよね」と語尾を柔らかくすることが多い
- 相手の名前を必ず呼んでから話し始める
```

**② 「価値観・経営哲学」の節に追記**
```markdown
7. **（新しく足す見出し）**：（集めたエピソードから読み取れる判断のクセ）
   例：現場の話を最初に聞いてから判断する。数字より先に「誰が困っているか」を聞く
```

**エピソードそのものは `data/knowledge.md` に追記**
```markdown
## 7. 社内から見た人物像（同僚・部下の証言）

- 会議では必ず現場の担当者に最初に話を振る
- 失敗の報告には「で、次どうする？」から入る
- ゴルフの話になると話が長くなる
（以下、集めた分だけ列挙）
```

> ⚠️ **個人が特定される内容や、本人が嫌がりそうな内容は入れない**こと。

**✅ persona.md と knowledge.md に、集めた内容が反映された**

### 2-2　AIの回答を作る 【制作】60分

1. アプリを起動する
   ```bash
   cd ai_sasaki
   GEMINI_API_KEY=（キー） node server.js
   ```
2. ブラウザで `http://localhost:3000/stage.html` を開き、合言葉を入力
3. **入力欄に設問1を打ち込んで送信**
4. 出てきた回答を見て判断する

| 判断 | 次の行動 |
|---|---|
| 本人っぽい | 💾ボタンで保存し、**メモ帳にもコピー**（動画の原稿になる） |
| いまいち | もう一度送信して引き直す（何度でもOK） |
| 何度やっても違う | 2-1 に戻ってペルソナを追記・修正する |

5. 設問1〜5、および **#2の挨拶用原稿**（自己紹介＋ゴルフの趣味／30秒＝約150字）を作る

**✅ 6本の原稿（クイズ5＋挨拶1）がメモ帳に揃った**

### 2-3　プロデューサーが原稿を確認する 【プロデューサー】30分
- [ ] 本人が言わなそうな表現が混じっていないか
- [ ] 本人を貶める表現がないか

### 5-2　想定質問の回答を確定する 【制作】40分
1. `data/content/qa_presets.json` を開く
2. 5つの質問それぞれについて、`/qa.html` で一度生成する
3. 気に入った回答を `answer` の欄に貼り付ける

```json
{ "q": "趣味は何ですか？", "answer": "ゴルフです。休みの日はコースに出ています。……" }
```

4. 保存して再デプロイ

> 💡 `answer` を埋めると、本番は**AIを呼ばずに確定した文が出ます**（失敗しない）。

**✅ 5問すべての `answer` が埋まった**

### 5-3　★音声をキャッシュに焼き込む 【PC】10分　←最重要
**この工程で、本番の待ち時間がゼロになります。**

1. `/qa.html` を開く
2. 左の想定質問を **5つとも1回ずつクリック**する
3. 音声が鳴るのを最後まで確認する
4. もう一度クリックして、**画面右上が「音声：再生中（キャッシュ）」**になれば成功

**✅ 5問すべてで「キャッシュ」表示になり、押した瞬間に鳴る**
