# 周辺アンケート設計｜「みんなが知っている佐々木さん」

AIの解像度を決める、**最も費用対効果の高い工程**です。
公開情報だけでは「実績」しか分からず、クイズで一瞬で見破られます。
ここで集めた「人柄」がAIの回答品質を決めます。

- **本人の同意は不要**（顔や声を複製するわけではなく、周囲の人が自分の言葉で語るだけ）
- **今日から着手できる**唯一の重要工程
- 所要：作成30分／回答5分／集計60分

---

## 1. 設計の考え方

### 答えやすい聞き方にする

| ❌ 答えにくい | ✅ 答えやすい |
|---|---|
| どんな人ですか？ | **失敗を報告したとき、最初に何と言われましたか？** |
| 価値観は？ | **会議でよくする質問は？** |
| 口調の特徴は？ | **話し始めの第一声は？** |

**抽象的に聞かない。場面を指定して、セリフを思い出させる。**これだけで回答率と質が変わります。

### 匿名にする
- 本音（口ぐせ、渋い顔をする場面など）を引き出すため**匿名**が基本
- ただし**関係性だけは聞く**（部下／他部門／秘書で見え方が違うため）

### 目標
- **回答30件**（20件で最低ライン）
- 締切：**8/19(火)**

## 2. そのまま使える設問（Googleフォーム用）

### フォームのタイトル
```
【ご協力のお願い】佐々木社長 就任お祝い会 サプライズ企画アンケート
```

### 冒頭の説明文
```
9月1日の佐々木社長 就任お祝い会で、余興として「AI佐々木社長」をつくっています。

ニュース記事や講演の情報だけでは、社長の"実績"は分かっても"人柄"がまったく分かりません。
そこで、普段社長と接している皆さんの力をお借りしたいです。

・所要5分、匿名です
・いただいた内容はAIの調整に使わせていただきます
・当日は会場で「本物 vs AI」のクイズをします。ぜひ見破ってください
・集まったお声は、後日まとめて社長ご本人にお渡しする予定です

⚠️ サプライズ企画のため、社長ご本人にはナイショでお願いします！
```

---

### セクション1：あなたについて（1問）

**Q1. 社長との関わりを教えてください** ＜ラジオボタン・必須＞
- 直属の部下
- 同じ本部・部門
- 他部門
- 秘書・アシスタント
- 社外・その他

---

### セクション2：話し方（AIの"喋り方"をつくる）

> セクション説明：`社長の「言い方」を教えてください。一言でも大歓迎です。`

**Q2. 社長がよく使う言葉・口ぐせがあれば教えてください** ＜自由記述・必須＞
```
例：「なるほどね」「で、お客様はどう思う？」「まあ、やってみましょう」
```

**Q3. 社長が話し始めるときの「第一声」は？** ＜自由記述・任意＞
```
例：「そうですね……」「ちょっといいですか」
```

**Q4. 「これぞ社長の言い回し」というフレーズを1つ** ＜自由記述・任意＞
```
「〜」と言いそう、という形でお書きください
```

---

### セクション3：判断のクセ（AIの"考え方"をつくる）

> セクション説明：`社長が何を大事にしているか、行動から教えてください。`

**Q5. 社長が何かを決めるとき、一番重視していると感じるものは？** ＜自由記述・必須＞
```
例：現場がどう思うか／数字の根拠／お客様目線／スピード
```

**Q6. 会議で社長がよくする質問は？** ＜自由記述・任意＞
```
例：「それ、お客様にとってどういいの？」「誰が困ってるの？」
```

**Q7. 社長が渋い顔をする / 厳しくなるのはどんな時ですか？** ＜自由記述・任意＞
```
例：準備不足のとき／お客様目線が抜けているとき
```

---

### セクション4：人柄が出る場面（AIの"温度"をつくる）

> セクション説明：`ここが一番のキモです。具体的な場面を思い出してお書きください。`

**Q8. 褒めるとき、社長はなんと言いますか？** ＜自由記述・任意＞

**Q9. 失敗やトラブルを報告したとき、最初に何と言われましたか？** ＜自由記述・任意＞
```
実際に言われた言葉を、覚えている範囲でそのまま書いていただけると嬉しいです
```

**Q10. 一番「社長らしいな」と思ったエピソードを1つ教えてください** ＜自由記述・必須＞
```
短くて構いません。「〇〇な時に、△△していた」という形でどうぞ
```

---

### セクション5：意外な一面（クイズのネタになる）

**Q11. 社長の意外な一面・趣味・こだわりがあれば** ＜自由記述・任意＞
```
例：ゴルフの話になると急に長くなる／実は甘いものが好き
```

**Q12. 「佐々木社長といえば？」を一言で** ＜自由記述・必須＞

---

### セクション6：クイズのネタ募集（任意）

**Q13. 「こんな時、社長ならどうする？」——クイズにしたい場面があれば教えてください** ＜自由記述・任意＞
```
例：部下が大きな失敗をしたとき／全員が賛成している案に違和感があるとき
```

**Q14. その場面で、社長はどうすると思いますか？** ＜自由記述・任意＞

---

### 最後の文言
```
ご協力ありがとうございました！
当日の余興、ぜひ楽しみにしていてください。
```

## 4. 集計してAIに反映する手順（8/20）

集まった回答を、次のように振り分けます。

### ① 口ぐせ・言い回し（Q2〜Q4）→ `data/config.json`

```jsonc
"speechStyle": {
  "catchphrases": [
    "気が利くね！",
    "（Q2で3件以上出た言葉をここに追加）"
  ],
  "sentenceEndings": ["（Q4から特徴的な語尾）"],
  "fillerPhrases": ["（Q3の第一声）"]
}
```

> **3件以上から挙がった言葉だけ採用**します。1件だけの表現は個人の印象なので入れない。

### ② 判断のクセ（Q5〜Q7）→ `data/persona.md` の「価値観・経営哲学」節

```markdown
7. **判断の軸（社内アンケートより）**：
   意思決定の場では、まず現場の担当者に話を振ってから判断する。
   準備不足には厳しいが、挑戦の失敗は責めない。
```

### ③ 人柄・エピソード（Q8〜Q12）→ `data/knowledge.md` に新しい節

```markdown
## 7. 社内から見た人物像（社内アンケート／回答30件より）

### 褒めるとき
- 「よく見てるね」と、まず観察を褒める（複数の回答あり）

### 失敗の報告を受けたとき
- 「で、次どうする？」から入る
- 責める前に事実確認をする

### 意外な一面
- ゴルフの話になると話が長くなる
```

### ④ クイズのネタ（Q13〜Q14）→ 設問5問の材料に

Q13で複数人から挙がった場面は、**会場の誰もが「あるある」と思う設問**です。
そのままクイズに採用すると盛り上がります。

- [ ] **悪口・不満は採用しない**。お祝いの場です
