# 外部サービス 利用手順書

15分余興で使う3つの外部サービスの、契約から解約までの手順書です。
進行計画は [`EVENT_RUNDOWN.md`](EVENT_RUNDOWN.md) を参照。

| サービス | 用途 | 月額 | 使うパート |
|---|---|---|---|
| [HeyGen](https://app.heygen.com/) | 顔アバター動画 | $49 | #2 挨拶、#3 クイズ、#4 ループ動画 |
| [ElevenLabs](https://elevenlabs.io/) | ボイスクローン | $11 | #4 フリー質問 |
| **seedance** | オープニング動画 | 要確認 | #1 オープニング（→ [`OPENING_VIDEO.md`](OPENING_VIDEO.md)） |

> ⚠️ **3つとも月額サブスクです。イベント翌日に必ず解約してください（§7）。**

## §1 ★最初にやること：本人の同意取得

**これが済むまで、他の作業は一切始められません。**

HeyGen も ElevenLabs も、**他人の顔・声を複製するには本人の同意が規約上必須**です。
無断で作成することは規約違反であり、アカウント停止の対象になります。

### 1-1. 本人にお願いする内容（依頼テンプレート）

> 佐々木社長
>
> ○月○日のお祝い会の余興で、社長の「AI分身」を作らせていただきたく、
> ご協力をお願いできますでしょうか。
>
> **お願いしたいもの（合計15分ほど）**
> 1. 同意確認の動画（スマホでQRを読んで撮影、1分）
> 2. アバター用の動画（正面・2〜5分）
> 3. 音声サンプル（静かな場所で3〜5分の朗読）
> 4. クイズ用の設問5問へのご回答（後日、紙かメールで）
>
> **利用範囲**：当日の余興のみ／後日の社内共有は（可・不可）
> **データの扱い**：イベント終了後にすべて削除いたします

### 1-2. 合意しておくこと

- [ ] 顔・声の利用範囲（当日限りか、後日の社内共有も可か）
- [ ] イベント後に**アバター・音声クローンを削除**すること
- [ ] 辛口ネタ・内輪ネタを入れる場合は、その内容の了承

> 💡 **サプライズにできない代わりに**：本人が仕込みに参加すれば、#3 の本人回答も
> 事前にもらえます。驚かせる相手を「会場の200人」に切り替えましょう。

**同意が得られない場合** → 外部サービス3つとも不要。このリポジトリのアプリ
（イラストアバター＋テキスト）だけで構成できます（費用ゼロ）。

## §2 HeyGen（顔アバター動画）— $49/月

### 2-1. 契約
1. https://app.heygen.com/ にアクセスし、アカウント作成
2. **Creator プラン（$49/月）** を選択
   - 月額と年額の選択に注意。**必ず月額（Monthly）**を選ぶ
3. 支払い情報を登録

### 2-2. 本人の同意動画を取得
1. HeyGen 管理画面で **Avatar → Create Avatar → Video Avatar** を開く
2. 本人以外が作成する場合、**同意動画（Consent Video）の提出を求められます**
3. 画面に表示される**QRコードを本人に送る**
   → 本人が自分のスマホでQRを読み取り、その場で同意動画を撮影・送信できます
   （本人が同席していなくてもOK）
4. 同意動画の中で、本人が指定された文言を読み上げます
5. HeyGen の審査を待つ（数十分〜1日）

> ⚠️ 同意動画に映る人物と、アバター素材に映る人物は**同一人物である必要**があります。

### 2-3. アバター用の動画を撮影（本人にお願いする）

| 項目 | 条件 |
|---|---|
| 長さ | 2〜5分 |
| 構図 | 正面・上半身。カメラは目線の高さ |
| 背景 | 無地・シンプル（白壁など） |
| 照明 | 顔に均一に光が当たる。逆光NG |
| 動き | 自然に喋り続ける。大きく動かない |
| 音 | 静かな場所（この音声は §3 でも使えます） |
| 服装 | 当日と似た雰囲気だと違和感が少ない |

### 2-4. アバターを作成
1. 撮影した動画をアップロード
2. 学習完了を待つ（通常30分〜数時間）
3. プレビューで違和感がないか確認

### 2-5. 動画を書き出す（合計7本）

| # | 用途 | 本数 | 原稿の作り方 |
|---|---|---|---|
| #2 | 最初の挨拶（24秒） | 1本 | このリポジトリのアプリで生成 → 幹事が確認。**1文目は直前の映像への自己ツッコミ** |
| #3 | クイズのAI回答 | 5本 | 同上。5問ぶん |
| #4 | ループ用（喋らずに頷く・瞬きする素材） | 1本 | 無音または「ええ」「なるほど」程度 |

**手順**
1. **Create Video** → 作成したアバターを選択
2. スクリプト欄に原稿を貼り付け
3. 音声は **ElevenLabs の声を連携**するか、HeyGen 内蔵の日本語音声を選ぶ
   （連携方法は §3-5）
4. **Submit** → 生成完了後 **Download**（MP4）
5. ファイル名を再生順に：`01_opening.mp4` `02_greeting.mp4` `03_q1_A.mp4` …

> ⚠️ **必ずローカルに保存**してください。当日はネットに依存せずローカル再生します。

## §3 ElevenLabs（ボイスクローン）— $11/月

### 3-1. 契約
1. https://elevenlabs.io/app/subscription/creative にアクセス
2. **Creator プラン（$11/月）** を選択（商用利用可・音声クローン利用可）
3. 支払い情報を登録

### 3-2. 本人の音声サンプルを収録（本人にお願いする）

| 項目 | 条件 |
|---|---|
| 長さ | 3〜5分（長いほど品質が上がる） |
| 環境 | 静かな部屋。エアコン・空調の音も切る |
| 機材 | スマホの標準録音でも可。可能ならピンマイク |
| 内容 | 新聞記事や自社サイトの文章を普通に朗読 |
| 話し方 | 抑揚をつけすぎず、いつもの話し方で |
| 形式 | mp3 または wav |

> 💡 §2-3 のアバター撮影の音声を流用できます。同じ収録で済ませると本人の負担が減ります。

### 3-3. 同意の確認
- 音声アップロード時に「**この声を複製する権利を持っている**」という確認にチェックが必要です
- 本人以外の声を使う場合、**本人の同意を文書で保管**しておいてください
  （§1 の依頼メールの返信で構いません）

### 3-4. 音声クローンを作成
1. 左メニュー **Voices → Add a new voice**
2. **Instant Voice Cloning**（数分の音声でOK・すぐ使える）を選択
   - より高品質にしたい場合は **Professional Voice Cloning**（本人確認あり・学習に数時間）
3. 音声ファイルをアップロード、名前を付ける（例：`sasaki-voice`）
4. 同意のチェックを入れて作成
5. **Text to Speech** で試し打ちし、日本語の発音を確認

> ⚠️ 日本語は固有名詞の読み間違いが起きやすいです。「佐々木」「Vポイント」など
> 当日使う語を必ず事前に読ませて確認してください。読み間違える場合は
> ひらがなで書く（例：「ぶいぽいんと」）と直ることがあります。

### 3-5. HeyGen と連携する（#2・#3 の動画で本人の声を使う）
1. ElevenLabs で **API キー**を発行（Profile → API Key）
2. HeyGen の **Settings → Integrations → ElevenLabs** に API キーを貼る
3. 動画作成時の音声選択に、作成した `sasaki-voice` が出てくる

### 3-6. このアプリと連携する（★推奨・待ち時間が半分になる）

ElevenLabs をこのリポジトリのアプリに繋ぐと、**フリー質問オペレーター卓**（`/qa.html`）で
**ワンクリックで「回答生成 → 音声再生」まで完結**します。手作業でコピペする必要はありません。

**設定手順**
1. ElevenLabs で **API キー**を取得（左下のアカウント → API Keys）
2. **Voice ID** を取得（Voices → 作成した音声 → ID をコピー）
3. アプリの `.env` に追記：
   ```
   ELEVENLABS_API_KEY=（APIキー）
   ELEVENLABS_VOICE_ID=（Voice ID）
   ```
4. サーバーを再起動
5. `/qa.html` を開き、画面右上が **「音声：接続OK」** になれば成功

**★リハーサルで必ずやること（本番の待ち時間がゼロになります）**
- `/qa.html` の**想定質問5つを1回ずつクリック**しておく
- 生成された音声は**サーバーにキャッシュ**されるため、本番は**押した瞬間に再生**されます
- 回答文を固定したい場合は `data/content/qa_presets.json` の `answer` に文章を書く
  （空欄なら当日その場で生成、埋めておけば確認済みの文が確実に出る）

### 3-7. 当日の操作（オペレーター卓）

```
① 演者が質問を復唱する
② 想定質問リストに近いものがあれば → クリックで即再生（待ち時間ゼロ）
   想定外の質問なら       → 入力欄に打ち込んで Enter（10〜20秒）
③ 音声がPAから流れる。裏ではループ動画が再生されている
④ 音声が出なくても、画面に回答の文字が大きく出るので演者が代読できる
```

**待ち時間**：想定質問なら**ゼロ**、想定外でも10〜20秒。§6 の安全策とあわせて運用してください。

- **カットは2本生成する**：29.21–36.18秒（踊る／4小節）と **36.18–39.66秒（着地カット／2小節）**
- **同期の許容誤差と対策**（§5-5）── 黒みはズレを吸収しません
- 当日の運用（**音楽と動画を同時**に出す手順）

## §5 ★楽曲の扱い（湘南乃風「バブル」を使う場合）

**ここは慎重に進めてください。** 市販曲の扱いは、やり方によって必要な手続きが変わります。

### 何が問題か
- 会場でCDや配信音源を**流すだけ**（演奏）と、
  **動画に音を焼き込む**（複製）とでは、扱いが異なります
- **動画に焼き込む＝複製**にあたり、原盤権（レコード会社）と著作権（JASRAC等）の
  両方の処理が必要になる場合があります
- 社内イベントでも、会費制・会社主催の場合は「非営利・無料」の要件を満たさない
  可能性があります

### 安全な進め方（おすすめ順）

| # | 方法 | 手間 | 安全度 |
|---|---|---|---|
| 1 | **動画は無音で作り、会場のBGMとして別に流す** | 小 | ○ 会場のJASRAC包括契約でカバーされることが多い（要確認） |
| 2 | **権利フリー音源（ロイヤリティフリー）を使う** | 小 | ◎ 完全に安全 |
| 3 | 会社の法務・総務に確認して正規手続きを取る | 大 | ◎ ただし時間がかかる |

**方法1の実務**：オープニング動画は無音で書き出し、演者の合図で音響担当が
会場PAから楽曲を流す。**音楽と動画は同時にスタート**する（音源の冒頭1.57秒は無音）。

> 🚨 **この方式には固有のリスクがあります。** 音と映像が別ソースになるため、
> **スタートのズレがそのまま29.211秒の爆発のズレになります**（黒みでは救えません）。
> 対策は [`OPENING_VIDEO.md` §5-5](OPENING_VIDEO.md) を必ず読んでください。
> **会場の音の経路（PA経由かPC直結か）を8/26までに確認**しておくと、
> 「1人が音と映像を同時に出す」運用が使えるか判断できます。

**方法2の音源探し**：`royalty free music epic corporate` 等で検索。
[Pixabay Music](https://pixabay.com/music/)、[Uppbeat](https://uppbeat.io/) などが
無料〜低額で使えます（各サイトの利用条件を必ず確認）。

> ⚠️ 私は法律の専門家ではありません。会社のイベントで市販曲を使う場合は、
> **必ず社内の法務・総務部門に確認**してください。

## §6 #4 フリー質問の安全策（最大のリスク箇所）

ライブ生成は「質問を聞く→回答文→音声化→再生」で**15〜25秒の待ち**が出ます。
200人の前でこの沈黙は長く感じます。

### 対策A：想定質問を仕込む（推奨・必須）
- 出そうな質問を**5つ**選び、**回答音声を事前に生成してファイル保存**しておく
  - 「趣味は？」「若手へのアドバイスは？」「休日の過ごし方は？」
    「社長になって一番変わったことは？」「好きな食べ物は？」
- 挙手で出た質問がこれに近ければ、**保存済み音声を再生**（待ち時間ゼロ）
- 完全に想定外の質問だけライブ生成する

### 対策B：待ち時間を演出で埋める
- 演者が「AI社長、いま考えていますね……」と間をつなぐ
- ループ動画で頷かせる（考えているように見える）
- **無音で待たない**。これだけで体感の長さが半分になります

### 対策C：質問を先に集めておく
- #3 のクイズ中に、会場から質問を紙で集めておく（幹事が回収）
- 演者が選んで読む → その間にオペレーターが生成を始められる

### 対策D：ワンクリック化（実装済み）
`/qa.html`（フリー質問オペレーター卓）で、**回答生成→音声再生がワンクリック**になります。
さらに**リハーサルで再生した音声はキャッシュされる**ため、想定質問は待ち時間ゼロです。
設定は §3-6 を参照。

### 詰まったときの逃げ道
> 演者「AI社長、少し考え込んでいるようです。……この続きは、
> 皆さんのスマホでぜひ直接聞いてみてください！」→ #5 のクロージングへ
