## 2. 各パートの中身

### #0 演者自己紹介（1:00）
- 演者が自分の挨拶をする
- 最後に **AI佐々木社長を呼び出す** 振りをして、#1 の動画へ繋ぐ

### #1 オープニング動画（33秒）★構成確定

湘南乃風「バブル」に合わせた登場ムービー。**動画は無音、楽曲は会場PAから別に流す**。

> 🚨 **下記の秒数は「キメの瞬間が曲頭から22.0秒」という未検証の前提に乗っています。**
> **制作前に音源で実測してください**（15分・[`OPENING_VIDEO.md` §0](OPENING_VIDEO.md)）。
> ズレていた場合はシルエット区間の長さで吸収し、全尺と通し時刻が変わります。

| 秒 | 楽曲 | 画面 |
|---|---|---|
| 00–03 | イントロ | 黒み（**ズレ吸収バッファ**） |
| 03–13 | 盛り上がり | シルエット＋煽りテロップ |
| **13–22** | ドラム加速 | ★**逆光の中こちらへ歩いてくる**（カウントダウン「3・2・1」を重ねる） |
| **22** | **ワッショイ！！** | ★**カメラ目前で立ち止まる＋背後が大爆発＋お札が舞う** |
| 22–29 | サビ | お札が舞う中、金のスーツの社長が踊り狂う |
| **29–33** | サビ | ★**急に動きを止め、ネクタイを直して会釈 → 暗転**（着地カット） |

- 制作：**seedance**＋編集ソフト → **詳細は [`OPENING_VIDEO.md`](OPENING_VIDEO.md)**
- **00–22秒は本人素材が不要**なので、合意前に先行制作できる（歩きは逆光で顔を飛ばす）
- ★**爆発は22秒に固定**。楽曲の最大の一撃（ワッショイ）と映像の最大の一撃を同じ瞬間に揃える
- ★**お札は22秒から33秒まで降り続けさせる**。この演出は **#2の書き出し**
  「現金が舞っておりましたが、私、キャッシュレス推進派でございます」**とセット**
- 当日は**音楽が先、動画が後**の順で再生（黒み3秒がズレを吸収する）
- ★**末尾3秒の着地カットが繋ぎの本体**。爆アゲのままブツッと終わると次が冷えるため、
  映像の中で「熱狂→静止」まで見せ切る（[`OPENING_VIDEO.md` §6](OPENING_VIDEO.md)）
- 着地カットが作れない場合は**パターンB（暗転＋テロップ／33秒）**、
  尺を変えたくない場合は**パターンA（決めポーズで静止／30秒）**に落とす

### #1.5 受け（3秒）★温度差の橋渡し
> 演者「……**登場！**」

映像が着地しているので、**煽らず短く受けて即つなぐ**のが正解。
この間に音響が楽曲をフェードアウトさせる。
※パターンA（30秒・着地カット無し）の場合のみ、
「……**登場！ AI佐々木社長です！**」＋拍手煽りで**5秒**受け、#2は 1:35 開始。

### #2 AI佐々木さん 最初の挨拶（24秒）
- **書き出しは先ほどの映像への自己ツッコミ**にする
  > ★本命：「……ただいまの映像、**現金が大量に舞っておりました**が。
  > 　　　　私、**キャッシュレス推進派**でございます。」

  決済会社の社長が現金を降らせているという一番大きな違和感を自分から拾う。
  これで爆アゲとの落差が「ギャップの笑い」に変わる
- そのあと自己紹介＋趣味（ゴルフ）へ
- 制作：**HeyGen**（月額 $49）で事前生成した動画を再生
- 原稿はこのリポジトリのアプリで生成 → 幹事が確認 → HeyGen に流し込む

### #3 本物 vs AI クイズ（8:00）★本編
- 「**こんな時どうする？**」という問いに、本人の回答とAIの回答を並べる
- **どちらが本物っぽいか**を会場が当てる。**5問**（1問あたり約95秒）
- 事前に「**他者から見える佐々木さん**」をAIのコンテキストに投入しておく
  → 投入先はこのリポジトリの `data/persona.md` / `data/knowledge.md`

**1問あたりの流れ（約95秒）**

| 秒 | 内容 |
|---|---|
| 0–20 | 演者が設問を読む（「こんな時、どうしますか？」） |
| 20–40 | **A** の回答を再生（HeyGenアバター動画） |
| 40–60 | **B** の回答を再生 |
| 60–75 | 「Aだと思う人、拍手！」「Bだと思う人、拍手！」 |
| 75–95 | 正解発表 → **ご本人に一言もらう**（ここが一番笑う） |

> 💡 **設問の作り方**：正解がバレにくいのは「価値観は同じだが具体例が違う」問い。
> 例：「部下が大きな失敗をしました。最初に何と声をかけますか？」

### #4 フリー質問（2:30）
- 挙手制でその場の質問に答える
- **アバターのループ動画を再生しながら、ElevenLabs のボイスクローンで喋らせる**
- 制作：**ElevenLabs**（月額 $11）→ [手順書 §3](SERVICE_SETUP.md)

> ⚠️ **ここが唯一のライブ生成＝最大のリスク**です。1問あたり「質問を聞く→回答文を作る→
> 音声化→再生」で15〜25秒の待ちが発生します。[手順書 §6](SERVICE_SETUP.md) の
> 安全策（想定質問の仕込み／待ち時間の埋め方）を必ず読んでください。

### #5 クロージング（1:00）
- 演者が締めの挨拶
- **みんなのスマホで試せるAI佐々木さん**を紹介 → QRを表示
  → このリポジトリのアプリ（合言葉入場）。二次会でも遊べる

## 4. ★最重要：本人の同意が必須（サプライズ不可）

**HeyGen も ElevenLabs も、他人のアバター・音声クローン作成には本人の同意が規約上必須**です。

- HeyGen：**本人が同意動画を撮影**する必要がある（本人のスマホからQR経由で提出可能）
- ElevenLabs：**本人の同意確認**と本人の音声サンプルが必要

つまり **「本人に内緒のサプライズ」は実現できません**。幹事から本人に、
「余興でAI分身を作りたい。顔と声の素材をください」と依頼するところから始めてください。

> 💡 **見方を変えると好都合**：本人が仕込みに参加することで、#3 のクイズの回答も
> 事前にもらえます。本番の驚きは「**会場200人にとってのサプライズ**」に切り替えましょう。

**同意が得られない場合**：顔・声を使わず、このリポジトリのアプリ（イラストアバター＋
テキスト）だけで構成できます。その場合は外部サービス3つとも不要（費用ゼロ）になります。

## 5. 「他者から見える佐々木さん」の集め方

#3 のクイズでAIの回答精度を上げるための素材です。以下のいずれかで集めます。

1. **事前アンケート**（推奨）：Slack や Google フォームで
   「佐々木さんといえば？」「こんな時こう言われた、というエピソード」を募集
2. **このリポジトリのアプリの投稿機能**：QRを事前配布し、📮ボタンから集める
   （`data/config.json` の `eventMode.memoryEnabled` が `true` で有効）
3. 幹事・側近5名へのヒアリング

集めた内容は `data/persona.md` の「話し方・口調」「価値観」節、および
`data/knowledge.md` に追記します。**追記後は必ず #3 の回答を再生成**してください。

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| 本人の同意・素材が間に合わない | アプリのみ構成に切り替え（費用ゼロ・§4参照）。判断期限を2週間前に設定 |
| #4 のライブ生成が詰まる | 想定質問の音声を事前に用意。詰まったら「後ほど直接どうぞ」で切り上げる |
| 動画が再生できない | 全動画をローカルに保存し、ネット非依存で再生。予備PCにもコピー |
| 楽曲の権利で止まる | 権利フリー音源に差し替え（#1の代替案・[手順書 §5](SERVICE_SETUP.md)） |
| #1爆アゲ→#2挨拶で会場が冷える | **動画の末尾に着地カット**（熱狂→静止）を入れる。リハで空気が落ちたら動画を作り直す（[`OPENING_VIDEO.md` §6](OPENING_VIDEO.md)） |
| 尺が押す | #4 の質問数で調整（2:30 → 最少50秒まで圧縮可） |
| クイズで会場が沈黙 | 拍手の代わりに「Aの人は右手、Bの人は左手を挙げて」に切替 |

**当日 紙で持つもの**：設問5問と正解、#4の想定質問と回答、動画の再生順リスト。
