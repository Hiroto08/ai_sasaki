# 15分余興 進行台本｜佐々木社長 就任お祝い会

- 想定：200名規模・会場貸切・**ご本人在席**
- 持ち時間：15分（転換込み）
- 使うもの：スクリーン（プロジェクタ）1面、司会マイク2本、参加者のスマホ、QR掲示

---

## 0. 企画のコンセプト

**「もう一人の佐々木さんが、お祝いに来てくれました」**

会場に *AI佐々木社長* が登場し、①全員が自分のスマホで話しかけられる、
②ご本人とAIが直接対決する、③最後にAIからご本人へお祝いを述べる、という三部構成。

**成功の鍵は「本人いじり」ではなく「本人と一緒に笑う」構図にすること。**
AIはあくまで"よくできた出来の悪い分身"であり、最後は必ずご本人を立てて締める。

### 事前に必ず押さえること
- [ ] **ご本人（または幹事経由）に企画の了承を取る**。サプライズにする場合も、
      幹事側で内容を確認し、写真・氏名の使用可否を確認しておく
- [ ] 辛口モードで使う内輪ネタ（`spicyPunch` 等）は、**その場にいる人が笑えるもの**に限定
- [ ] 未公開情報・人事・数字に触れない設定になっているか最終確認（ガードレール済）

## 1. タイムテーブル（15分）

| 時間 | パート | 内容 | 主担当 |
|---|---|---|---|
| 0:00–1:30 | **導入** | 「本日、もう一人の佐々木さんをお招きしています」→ スクリーンにAI登場 | 司会 |
| 1:30–3:00 | **全員参加** | QRと合言葉を発表、200人が一斉に入場。各自スマホで雑談 | 司会＋運営 |
| 3:00–6:00 | **第1幕：就任のご挨拶** | AI佐々木がスクリーンで就任の抱負を語る＋会場から質問 | 司会（操作） |
| 6:00–10:00 | **第2幕：本人 vs AI 対決** | 同じ質問への回答を見比べ「どっちが本物？」 | 司会＋ご本人 |

## 2. 詳細台本

### 【0:00–1:30】導入

> 司会：「本日は佐々木社長のご就任、誠におめでとうございます。
> …実は本日、**もう一人の佐々木さん**にもお越しいただいております。」

- スクリーン切替 → **ステージ画面**（`/stage.html`）を投影。アバターが登場
- 司会がプリセット①「登場のあいさつ」をクリック
- AI「本日はお招きいただきありがとうございます。私は公開情報だけでつくられた
  AIパロディ社長です。本物ではありませんが、サービス精神は本物です。」
- 会場：笑い ＋ ご本人の反応をカメラで抜くと最高

**ポイント**：ここで「非公式のAIパロディ」であることを明るく宣言してしまう。
免責がネタとして機能し、以降の内容が全部「お約束」になる。

### 【1:30–3:00】全員参加（QR＋合言葉）

> 司会：「実はこのAI社長、皆さんのスマホからも話しかけられます。
> スクリーンのQRを読み取って、合言葉は…**『きがきくね』**！」

- スクリーンに**QRコードと合言葉**を大きく表示（この間はスライドに切替）
- 200人が一斉アクセス。「おみくじ」「診断」ボタンで各自遊んでもらう
- ざわつきが最高潮になったところで司会が回収

**ポイント**：全員がスマホを触っている時間を必ず作る。ここで会場が"自分ごと"になる。
アクセスできない人がいても進行に支障がない設計（以降はスクリーン主導）。

### 【3:00–6:00】第1幕：就任のご挨拶＋会場質問

- 司会がプリセット②「就任の抱負を聞かせてください」をクリック → 大画面に回答
- 続けてプリセット③「これからの三井住友カードをどうしたいですか？」
- **会場から2〜3問**、その場で質問を受けて入力（司会が読み上げながら打つ）
  - 拾いやすい質問例：「社長の一日のスケジュールは？」「趣味は？」「部下に望むことは？」
- ゴルフ好き設定を入れてあるので、趣味の話題は鉄板で盛り上がる

**運営Tips**：質問は事前に3つ仕込んでおき、会場から出なければそれを使う。

### 【6:00–10:00】第2幕：本人 vs AI「どっちが本物？」★メイン

**最も盛り上がるパート。事前準備が必要。**

#### 事前準備（前日まで）
1. ご本人（または幹事）に**3つの質問**に答えてもらい、回答を書き起こしておく
   - 例：「入社の決め手は？」「大事にしている言葉は？」「休日の過ごし方は？」
2. 同じ質問をAIに投げて回答を保存しておく（当日その場で生成でも可、ただし時間リスク）

#### 当日の進行
> 司会：「ここからは本人にもご登壇いただきます。同じ質問への回答をご覧ください。
> **AとB、どちらが本物の佐々木さんでしょうか？**」

- スクリーンにA/B両方の回答を並べて表示
- **会場投票**：「Aだと思う人は拍手！」「Bだと思う人は拍手！」（音量で判定・低リスク）
  - もしくは「Aだと思う人は起立」で視覚的に
- 正解発表 → ご本人に一言コメントをもらう（ここが一番笑いが起きる）
- これを3問繰り返す（1問あたり約80秒）

**ポイント**：AIが本人に勝つ（＝間違われる）と大受けする。
逆に外されても「AIまだまだですね」と本人が言って笑いになるので、どちらに転んでも成立する。

### 【10:00–12:30】第3幕：辛口モード解禁

> 司会：「実はこのAI社長、**もう一つのモード**があります。…**辛口モード**！」

- ステージ画面の辛口トグルをON → **アバターの周りに赤い覇気**が出る演出
- 会場：どよめき
- 司会が仕込みの質問を投げる（例：「最近の私の仕事ぶりをどう思いますか？」）
- AIが「率直に言います」「数字で言うと？」と切り込む

**内輪ネタの仕込み**：`data/content/greetings.json` の `spicyPunch` に
その場で笑いが起きる一言（例：「森っちなんでいるの？」）を設定しておくと、
辛口モード後の最初の回答の前に、2秒タメてから決め台詞が出る。
※デフォルトは空（非表示）。**使う場合は、いじられる本人の了承を取ってから設定すること。**

### 【12:30–15:00】フィナーレ：AIからご本人へ

> 司会：「最後に、AI佐々木社長から、本物の佐々木社長へメッセージがあるそうです。」

- 通常モードに戻す（覇気が消える＝空気が切り替わる）
- プリセット⑨「本物の佐々木社長へ、就任のお祝いメッセージを」をクリック
- 大画面にお祝いメッセージが表示される（少ししんみりする内容にしておく）
- AI「…私は公開情報しか知りません。ここから先の物語は、本物のあなたにしか書けません。
  ご就任、誠におめでとうございます。」
- **スクリーン暗転 → ご本人にマイク** → 締めの挨拶へ

**ポイント**：笑いで終わらせず、最後の30秒で温度を上げて主役に返す。
これで「面白かった」が「いい会だった」に変わる。

## 3. AI佐々木さんの活用方法まとめ

| 使い方 | 場面 | 効果 |
|---|---|---|
| **スクリーン主役** | 第1幕・第3幕・フィナーレ | 進行を持たせられる。司会の負担が減る |
| **200人の手元** | 全員参加パート | 全員が"体験"する。会場の一体感 |
| **本人との対比** | 第2幕 | 本人の人柄・実績が浮き彫りになる（＝一番のお祝い） |
| **辛口モードの演出** | 第3幕 | 見た目（赤い覇気）で分かる転換。ショーとしてのメリハリ |
| **お祝いの代弁者** | フィナーレ | AIが言うことで照れずに讃えられる |

### 会後の活用（おまけ）
- 会場に**QRを残しておく**と、二次会や後日も遊べる
- 「今日の写真＋AI社長のおみくじ」をお土産カードにするのも喜ばれる

## 4. 当日の運用チェックリスト

### 機材・環境
- [ ] スクリーンに `/stage.html` を全画面表示（F11）、ブラウザのブックマークに登録
- [ ] **会場Wi-Fi**：200人同時接続に耐えるか事前確認。厳しければ「一斉アクセスは1分ずらす」案内
- [ ] 有線LAN or テザリングでステージ用PCだけは確実にネット接続を確保
- [ ] 音声読み上げは**使わない**（会場BGM・マイクと競合するため）

### 設定
- [ ] `.env` の `PASSPHRASE` をお祝い会用に変更（例：`おめでとうございます`）
- [ ] `MAX_TURNS` を 20 程度に（15分の会なら十分。コスト抑制）
- [ ] `MAX_PER_MIN` は 10 に上げる（司会が連続操作するため）
- [ ] `MODEL=gemini-2.5-flash`（速度重視。応答2〜3秒）
- [ ] 写真を使う場合は `public/avatar.png` を配置（**要ご本人了承**）

### リハーサル（前日必須）
- [ ] プリセット①〜⑨を通しで押して、回答の質を確認（変なら文言を調整）
- [ ] 辛口モードの覇気アニメーションがプロジェクタで見えるか確認（明るさ調整）
- [ ] 第2幕のA/B回答を印刷しておく（**通信障害時のバックアップ**）
- [ ] スマホ実機でQR→合言葉→チャットを確認

### リスクと対策
| リスク | 対策 |
|---|---|
| 会場Wi-Fiが落ちる | ステージPCはテザリング。全員参加パートは飛ばしても進行可能な構成 |
| AI応答が遅い/失敗 | APIエラー時は自動でデモ定型応答にフォールバック（実装済）。無言にならない |
| 回答が滑る | プリセットは前日に検証済のものだけ使う。その場の自由入力は第1幕のみ |
| 想定外の発言 | ガードレールで人事・機密・人物批判は回答拒否。それでも不安なら第3幕を短縮 |
| 時間超過 | 第2幕を3問→2問に減らせば2分短縮できる（調整弁） |
