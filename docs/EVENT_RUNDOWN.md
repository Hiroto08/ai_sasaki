## 2. 各パートの中身

### #0 演者自己紹介（1:00）
- 演者が自分の挨拶をする
- 最後に **AI佐々木社長を呼び出す** 振りをして、#1 の動画へ繋ぐ

### #1 オープニング動画（36.18秒）★実測確定

サイバーな光の演出で登場するムービー。★**楽曲は権利フリー／生成音源を使い、動画に焼き込む**。
当日は**動画を再生するだけ**で音も一緒に出るため、**同期ズレのリスクがありません**。

> ✔ **秒数は 2026/8/10 に音源を解析して確定**しました（[`OPENING_VIDEO.md` §0](OPENING_VIDEO.md)）。
> テンポ 137.81 BPM、1小節 1.7415 秒。**すべてのカット切り替えが小節線に乗っています。**

| 秒 | 小節 | 楽曲 | 画面 |
|---|---|---|---|
| 0.00–1.57 | — | **無音**（頭の余白） | 黒み |
| 1.57–3.09 | −16 | 音が立ち上がる | 黒みのまま |
| 3.09–15.28 | −15〜−9 | イントロ（歌なし） | シルエット＋煽りテロップ |
| **15.28–23.99** | −8〜−4 | **曲の構成が変わる** | ★**逆光の中こちらへ歩いてくる** |
| 23.99 / 25.73 / 27.47 | −3/−2/−1 | 加速 →**ブレイク** | カウントダウン「3」「2」「1」（各1小節） |
| **29.21** | **0** | ★**曲のドロップ（最大の一撃）** | ★**立ち止まる＋背後が青く大爆発＋光の粒子が飛散** |
| 29.21–32.69 | 0〜+2 | ドロップ後 | ★**白が引いて顔が現れる（正体判明）**＋テロップ「AI佐々木社長」 |
| **32.69–36.18** | +2〜+4 | | ★**キメ**：ネクタイを直しカメラ目線で会釈 → **暗転** |

- 制作：**HeyGen の AI Video Generator（Seedance 2）**＋編集ソフト
  → **生成プロンプトは [`OPENING_VIDEO.md` §3-0-2](OPENING_VIDEO.md)**（そのままコピペ可）
- **0–29.2秒は本人素材が不要**なので、合意前に先行制作できる（歩きは逆光で顔を飛ばす）
- ★**爆発は29.211秒**。楽曲側のドロップをこの位置に合わせて作ります
  → **映像は完成済みなので、動かすのは音楽のほう**（[`OPENING_VIDEO.md` §4-3](OPENING_VIDEO.md)）
- ★**踊らせない。** ここに合わせるべきは「動き」ではなく「**判明**」。
  正体を明かして、決めて、短く落とす
  → 制作面でも、いちばん引き直しの多かった「踊るカット」が不要になった
- ★**衣装は通常のダークスーツ**。演出は**AIらしいサイバーな青い光の粒子**
- ★**光の粒子は29.2秒から36.2秒まで舞い続けさせる**。この演出は **#2の書き出し**
  「盛大に光の粒が飛び散っておりました。あれ、全部私です」**とセット**
- ✅ **当日はPC担当が再生ボタンを押すだけ。**音も動画から出ます
  → 事前確認は「**PCの音が会場スピーカーから出るか**」の1点だけ
- ★**末尾2小節のキメで、映像はすでに静かに着地しています。**
  旧案（踊り狂ったまま終わる）で問題だった「爆アゲ→淡々とした挨拶で冷える」は
  設計から解消済み（[`OPENING_VIDEO.md` §6](OPENING_VIDEO.md)）

### #1.5 受け（3秒）
> 演者「……**登場！**」

映像が静かに着地しているので、**煽らず短く受けて即つなぐ**のが正解。
大声で煽ると逆に浮きます。楽曲は動画の中で36.18秒にフェードアウト済み。

### #2 AI佐々木さん 最初の挨拶（24秒）
- **書き出しは先ほどの映像への自己ツッコミ**にする
  > ★本命：「……ただいまの映像、盛大に**光の粒**が飛び散っておりました。
  > 　　　　あれ、**全部私です。**」

  飛び散った粒子を「自分の一部」と言い切ることで、**AIが実体を持たない**ことを笑いに変える。
  派手な登場を自分で回収しつつ、そのまま自己紹介にもなっている
- そのあと自己紹介＋趣味（ゴルフ）へ
- 制作：**HeyGen**（月額 $49）で事前生成した動画を再生
- 原稿はこのリポジトリのアプリで生成 → 幹事が確認 → HeyGen に流し込む

### #3 本物 vs AI クイズ（8:00）★本編
- 「**こんな時どうする？**」という問いに、本人の回答とAIの回答を並べる
- **どちらが本物っぽいか**を会場が当てる。**5問**（1問あたり約95秒）

> 🚨 **A/Bの回答は「並べたスライド」で見せ、正解発表でAI社長の動画を流します。**
> どちらか一方だけ動画にすると、**形式が答えを教えてしまい、1問目で全員が気づきます。**
> スライドなら形式が完全に対称で、**AとBを並べて見比べられる**利点もあります。
> スライドの体裁と「答えが漏れる典型パターン」は [`AVATAR_LOOK.md` §8](AVATAR_LOOK.md) を参照。
>
> ⚠️ **AIをA/Bどちらに置くかは問ごとにシャッフル**してください。毎回Aだと3問目で気づかれます。
- 事前に「**他者から見える佐々木さん**」をAIのコンテキストに投入しておく
  → 投入先はこのリポジトリの `data/persona.md` / `data/knowledge.md`

**1問あたりの流れ（約95秒）**

| 秒 | 内容 |
|---|---|
| 0–15 | 演者が設問を読む（「こんな時、どうしますか？」） |
| 15–40 | **A・Bを並べたスライドを表示**。演者が両方を同じトーンで読み上げる |
| 40–55 | 「Aだと思う人、拍手！」「Bだと思う人、拍手！」（スライドは出したまま） |
| **55–75** | ★**AI社長の正解発表動画**を再生（20秒） |
| 75–95 | **ご本人に一言もらう**（ここが一番笑う） |

> 💡 **設問の作り方**：正解がバレにくいのは「価値観は同じだが具体例が違う」問い。
> 例：「部下が大きな失敗をしました。最初に何と声をかけますか？」

### #4 フリー質問（2:30）
- 挙手制でその場の質問に答える
- **アバターのループ動画を再生しながら、ElevenLabs のボイスクローンで喋らせる**

> ⚠️ **ここが唯一のライブ生成＝最大のリスク**です。1問あたり「質問を聞く→回答文を作る→
> 音声化→再生」で15〜25秒の待ちが発生します。[手順書 §6](SERVICE_SETUP.md) の
> 安全策（想定質問の仕込み／待ち時間の埋め方）を必ず読んでください。

### #5 クロージング（1:00）

- **みんなのスマホで試せるAI佐々木さん**を紹介 → QRを表示
  → このリポジトリのアプリ（合言葉入場）。二次会でも遊べる

## 4. ★最重要：本人の同意が必須（サプライズ不可）

**HeyGen も ElevenLabs も、他人のアバター・音声クローン作成には本人の同意が規約上必須**です。

- HeyGen：**本人が同意動画を撮影**する必要がある（本人のスマホからQR経由で提出可能）
- ElevenLabs：**本人の同意確認**と本人の音声サンプルが必要

つまり **「本人に内緒のサプライズ」は実現できません**。幹事から本人に、
「余興でAI分身を作りたい。顔と声の素材をください」と依頼するところから始めてください。

> 💡 **見方を変えると好都合**：本人が仕込みに参加することで、#3 のクイズの回答も
> 事前にもらえます。本番の驚きは「**会場200人にとってのサプライズ**」に切り替えましょう。

**同意が得られない場合**：顔・声を使わず、このリポジトリのアプリ（イラストアバター＋
テキスト）だけで構成できます。その場合は外部サービス3つとも不要（費用ゼロ）になります。

## 5. 「他者から見える佐々木さん」の集め方

#3 のクイズでAIの回答精度を上げるための素材です。以下のいずれかで集めます。

1. **事前アンケート**（推奨）：Slack や Google フォームで
   「佐々木さんといえば？」「こんな時こう言われた、というエピソード」を募集
2. **このリポジトリのアプリの投稿機能**：QRを事前配布し、📮ボタンから集める
   （`data/config.json` の `eventMode.memoryEnabled` が `true` で有効）
3. 幹事・側近5名へのヒアリング

集めた内容は `data/persona.md` の「話し方・口調」「価値観」節、および
`data/knowledge.md` に追記します。**追記後は必ず #3 の回答を再生成**してください。

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| 本人の同意・素材が間に合わない | アプリのみ構成に切り替え（費用ゼロ・§4参照）。判断期限を2週間前に設定 |
| #4 のライブ生成が詰まる | 想定質問の音声を事前に用意。詰まったら「後ほど直接どうぞ」で切り上げる |
| 動画が再生できない | 全動画をローカルに保存し、ネット非依存で再生。予備PCにもコピー |
| 楽曲の権利で止まる | ✅ **解消済み。**権利フリー／生成音源に切替済み（[`OPENING_VIDEO.md` §4](OPENING_VIDEO.md)）。利用規約のスクショだけ保存しておく |
| ~~音楽と動画の再生がズレる~~ | ✅ **解消済み。**楽曲を動画に焼き込むため、ズレようがない。代わりに**PCの音が会場スピーカーから出るか**だけ事前確認する |
| 正体判明が伝わらない | テロップを大きく・長くする／爆発の白の引きを遅くして顔を見せる時間を増やす。**後方席から読めるか**をリハで確認（[`OPENING_VIDEO.md` §6](OPENING_VIDEO.md)） |
| **クイズの答えがスライドでバレる** | 文字数・行数・文体・読点の癖を揃える。AIを毎回同じ側に置かない（[`AVATAR_LOOK.md` §8](AVATAR_LOOK.md)） |
| 尺が押す | #4 の質問数で調整（2:30 → 最少50秒まで圧縮可） |
| クイズで会場が沈黙 | 拍手の代わりに「Aの人は右手、Bの人は左手を挙げて」に切替 |

**当日 紙で持つもの**：設問5問と正解、**A/Bの割り当て表（PC担当のみ）**、#4の想定質問と回答、再生順リスト。
