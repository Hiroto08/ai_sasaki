# 公開情報リサーチまとめ：佐々木丈也氏（三井住友カード社長）

リサーチ実施日：2026-07-15。直接インタビューが困難なため、公開情報（報道・インタビュー記事・
登壇情報・公式リリース）のみからペルソナを構築した。本ドキュメントはその出典と、
実在人物をモデルにする際の法的・倫理的留意点を記録する。

## 1. 人物プロフィール（公開情報）

- 1967年10月27日生まれ。1991年3月 明治学院大学経済学部卒業、同年 三井住友カード入社
- 保険事業、法人営業、商品企画 → 2012年 ネットビジネス事業部長 → 2017年 統合マーケティング部長
  → 2019年 執行役員 マーケティング統括部長 → 2020年 マーケティング本部長 → 専務執行役員 → 副社長
- 2026年3月9日発表、6月30日付で代表取締役社長に就任。**1967年の創業以来初の生え抜き社長**。
  前社長・大西幸彦氏は会長に。日経は「マーケティングに精通」と報道

## 4. 法的・倫理的留意点（本モックで講じた対策）

実在の、しかも本人同意のない人物をモデルにするため、以下を厳守する：

| リスク | 本モックでの対応 |
|---|---|
| 肖像権 | 実在の顔写真・容姿を再現するアバターは**使用しない**。汎用イラストのみ |
| パブリシティ権・音声 | 音声クローンは**作成しない**。端末標準の合成音声のみ |
| なりすまし/誤認 | 全画面に「非公式AIシミュレーション・本人の発言ではない」を常時表示。AI回答末尾にも明記 |
| 名誉毀損 | ペルソナは公開発言の範囲に限定。ガードレールで人物批判・未公開情報・断定的約束を禁止 |
| 商用利用 | 社内検証用モックに限定。社外公開・商用化は本人・同社の許諾が前提であることをREADMEに明記 |

**本格展開の条件**：本人および三井住友カード株式会社からの書面による許諾
（肖像・音声・発言データの利用範囲、期間、削除条件を含む）。許諾が得られた場合のみ、
