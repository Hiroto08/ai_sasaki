## 0. 🚨 最大の発見：現ペルソナと、社内の社長像は「別人」です

**現在の `persona.md` / `config.json` は公開インタビューだけで作りました。
その言葉が、340件の自由回答に一度も出てきません。**

| 現ペルソナのキーフレーズ | アンケートでの出現 |
|---|---|
| 「気が利くね！」 | **0件** |
| 「お客様の当たり前を当たり前に」 | **0件** |
| 「情緒的価値」 | **0件** |
| 「習慣化」 | **0件** |
| 「いいキャッシュレスがいい毎日をつくる」 | **0件** |

代わりに出てきたのは、まったく別の語彙です。

| 社内で見えている社長 | 人数 | 割合 |
|---|---|---|
| ★**「いいね」「いいじゃん」** | **14人** | **56%** |
| ★**タメ口（〜じゃん／〜じゃね？／〜ねーの？）** | **11人** | **44%** |
| 第一声が「いや〜」「まあ」「えー」 | 9人 | 36% |
| 「で？」「そもそも」 | 4人 | 16% |

> 💡 **これは矛盾ではありません。**
> 公開インタビューは**対外の言葉**、アンケートは**社内で本人が実際に喋っている言葉**です。
> どちらも本物ですが、**9/1の会場にいる200人が知っているのは後者**です。
>
> 🚨 **現状のまま出すと「全然似てない」と言われます。**
> #3のクイズは「本物 vs AI」なので、**似ていないと企画そのものが成立しません。**

**→ 結論：口調のベースを、公開インタビュー調から「社内で喋っている言葉」に全面的に寄せます。**
**経営メッセージ（顧客起点・情緒的価値など）は、中身として残します。**

## 2. 行間を読む

### 発見①　★口ぐせは「二層構造」になっている

回答は、まったく違う2つの語彙に割れます。

**【A層】近い人へのじゃれあい（6人・24%）**
```
死ねよ／殺すぞ／ころす／死刑だ／てめえでやれよ／知らねーよ／
知らん！聞いてねぇ！／ふっざけんなよ／お前！／
能力の無さを時間でカバーしないでくれる？（笑）
```

**【B層】感謝と肯定（4人・16%＋公式発言）**
```
ありがとう／サンキュー／すまん／お疲れさん／
「常に感謝の言葉を添えてくれます」／
「皆さん、おはようございます。佐々木です」から入り、まず日頃の尽力への感謝を述べる
```

> 💡 **矛盾ではなく、距離による使い分けです。**
> A層は「じゃれている」のであって、怒っていません。[2]の回答に全部（笑）が付いているのが証拠です。
>
> 🚨 **しかしAIには絶対に使わせません。**
> - 200人の公式行事で、**本人が目の前にいる**
> - スクリーンに出て、**動画として残る**
> - 文字にした瞬間、じゃれあいのニュアンスが落ちて**ただの暴言**になる
>
> ★**代わりに、A層の「エネルギー」だけを別の形で残します。**
> **タメ口の軽さ（いいじゃん／〜じゃね？）と、軽いイジり（で？／そもそもさ）**で表現する。
> これなら誰も傷つけずに「あ、社長っぽい」が出ます。

### 発見②　この人は「肯定から入って、そこから詰める」

並べると順番が見えます。

```
「いいじゃん」          ← まず肯定する（56%が言及）
   ↓
「でもさ、」「そもそもさ」  ← ここから入る
   ↓
「それ、何がいいの？」     ← 詰める
「お客さん、嬉しいんだっけ？」
「で？」
```

[10]の回答が完璧です ──「**いいと思うよ。でもさ、**」／「**任せるけど、ここは・・**」

> ★**否定から入らない人**です。ここは #4 のフリー質問で効きます。
> どんな質問が来ても、**まず「いいじゃん」と受けてから本題に入る**と、
> それだけで本人らしさが出ます。

### 発見③　会議での定型質問は「それ、何がいいの？」

```
それは誰のためになるの？／誰のためにやってんの？／お客さんにとって何がいいの？／
それ、何が良いの？／それは何がいいの？ 今までと何が違うの？／
それで、何がいいんだっけ。／やる意味はあるの？
```

**7人が、ほぼ同じ質問を書いています。**言い回しの揺れはありますが、**構造は同一**。

> ★**「それ、何がいいんだっけ？」を、AI社長の決め質問として固定します。**
> #3のクイズでも #4 でも使えます。

### 発見④　一貫テーマは「偉くならない」

### ★重要：Q14の使い方

**Q14は「社員の予想」であって、正解ではありません。** これは弱点ではなく、**むしろ強みです。**

```
本人の回答（8/24までに紙で回収）  →  クイズの「正解」
アンケートQ14（社員の予想）        →  ★AI側の回答を作る材料
```

> ★**つまり、クイズの難易度を設計できます。**
>
> | AI側の回答を… | 結果 |
> |---|---|
> | **社員の平均的な予想（Q14）に寄せる** | **当てやすくなる**（＝会場が正解して盛り上がる） |
> | **本人の実際の答えに寄せる** | **当てにくくなる**（＝AIの精度が際立つ） |
>
> **5問すべてを難しくしないでください。**
> 最初の1〜2問は当てやすくして会場に成功体験を作り、後半で難しくするのが定石です。
