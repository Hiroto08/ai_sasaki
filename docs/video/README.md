# 素材の置き場所

`docs/show.html`（本番進行ランナー）が使う**動画5本とQR画像1枚**です。

## ★ファイル名は何でも構いません

**開始画面に動画とQR画像をまとめてドロップすれば、上から順に割り当たります。**
動画は動画の枠へ、画像はQRの枠へ、自動的に振り分けられます。
名前を変える必要はありません。OneDrive などから落としたまま使えます。

- **まとめてドロップ** … ファイル名順に、上から割り当て
- **1行にドロップ** … その枠だけ差し替え
- **サムネイルをクリック** … 音なしで再生して中身を確認
- **▲▼** … 割り当てを入れ替え

> 🚨 **まとめてドロップしたら、必ず割り当てを確認してください。**
> 並ぶ順はファイル名順なので、名前によっては意図と違う順になります。
> サムネイルで中身を見て、違っていたら ▲▼ で直します。

## 毎回ドロップするのが面倒な場合

このフォルダに下の名前で置いておくと、**開いた時点で自動的に割り当たります。**

| 順 | ファイル名 | 中身 |
|---|---|---|
| ② | `01_appearance.mp4` | 登場動画 |
| ③ | `02_intro.mp4` | 自己紹介動画 |
| ④ | `03_q1.mp4` | Q1 |
| ⑤ | `04_q2.mp4` | Q2 |
| ⑥ | `05_q3.mp4` | Q3 |
| ⑦ | `assets/qr/qr_slide_1920.png` | 入場QR画像（**このフォルダではなくリポジトリの `assets/qr/`**） |

（①タイトルは文字だけなのでファイル不要です）

## 形式

- 動画は **MP4（H.264 + AAC）／1920×1080** が確実。`.mov` `.webm` `.m4v` も読み込めます
- QR画像は **PNG / JPEG / WebP / SVG**。1920×1080 のスライド画像がそのまま使えます
- 音声は動画に焼き込む（別ファイルにしない）

## まだ動画が無くても通し稽古できます

割り当てのない場面は「動画がまだ割り当てられていません」という代役が出るので、
**進行の練習は動画が揃う前からできます。**

## ★このフォルダの中身はコミットされません

容量が大きく、本人の顔・声を含むためリポジトリには入れません
（`.gitignore` 済み。このREADMEだけ共有されます）。
