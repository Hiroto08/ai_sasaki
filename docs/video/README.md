# 動画の置き場所

`docs/show.html`（本番進行ランナー）が読み込む動画を、**このフォルダに**置きます。
ファイル名は下の表のとおりにしてください（名前が違うと読み込まれません）。

| ファイル名 | 中身 | 尺 |
|---|---|---|
| `01_opening.mp4` | #1 オープニング動画（楽曲は焼き込み済み） | 36.18秒 |
| `02_greeting.mp4` | #2 AI社長 最初の挨拶 | 24秒 |
| `03_q1_reveal.mp4` | Q1 正解発表 | 20秒 |
| `04_q2_reveal.mp4` | Q2 正解発表 | 20秒 |
| `05_q3_reveal.mp4` | Q3 正解発表 | 20秒 |
| `06_q4_reveal.mp4` | Q4 正解発表 | 20秒 |
| `07_q5_reveal.mp4` | Q5 正解発表 | 20秒 |

## 形式

- **MP4（H.264 + AAC）／1920×1080**。ブラウザでそのまま再生できる形式にする
- 音声は動画に焼き込む（別ファイルにしない）

## まだ動画が無くても通し稽古できます

ファイルが無い場面は「動画がまだありません」という代役が出るので、
**進行の練習はいまのうちからできます。**
起動画面に、見つからなかったファイル名が一覧で出ます。

## ★このフォルダの中身はコミットされません

動画は容量が大きく、本人の顔・声を含むため、リポジトリには入れません
（`.gitignore` 済み。このREADMEだけ共有されます）。
**別のPCで開く場合は、動画を手でコピーしてください。**
