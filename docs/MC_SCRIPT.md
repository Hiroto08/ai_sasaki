# 就任お祝い会 15分余興 進行台本（司会用・完全台詞版）

司会が手に持って読める版。**「 」の中はそのまま読む台詞**、`▸` はト書き（読まない）、
`[ ]` はオペレーター操作。戦略・事前準備は [`EVENT_RUNDOWN.md`](EVENT_RUNDOWN.md) を参照。

> **大前提**：本番中、ステージ画面の **📝台本モードはONのまま**。AIは呼ばれず、前日に確認済みの
> 原稿が再生されます。**フィナーレ原稿も開演前に確定済み**。画面が固まっても紙を読めば成立します。

## これだけは守る

1. **台本モードは本番中ONのまま。** 触らない
2. **自由入力は仕込み文の貼り付けのみ。** その場で考えて打たない
3. **フィナーレ前に必ずBGMを絞る。** 音が鳴っていると感動しない
4. **フィナーレ中、司会は一言も喋らない。** 沈黙に耐える
5. **最後は必ずご本人にマイクを返す。** AIで終わらせない

## 詰まったときの逃げ道

| 症状 | その場でやること |
|---|---|
| 画面が固まった | 紙のフィナーレ原稿を司会が読み上げる。それで成立する |
| 回答が出ない | 台本モードON確認。だめなら次のキューへ飛ばす |
| 投稿が少ない | 件数は読み上げない。幹事の投稿分だけでフィナーレは成立する |
| 変な投稿が流れた | 📮「声を表示」をOFF。それだけで消える |
| ご本人が乗らない | 第2幕は司会だけで回す。コメントは求めない |
| 押している | 第2幕の第3問（8:00）を飛ばす。1分縮まる |
