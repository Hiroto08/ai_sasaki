## これだけは守る

1. **設問は紙のとおり読む。** 言い換えない（正解が漏れる）
2. **動画中は喋らない。** 画面に集中させる
3. **#4 で無音で待たない。** 間を埋める台詞を必ず入れる
4. **12:00 を過ぎたら質問を打ち切る。** 尺は #4 で調整する
5. **最後は必ずご本人に向き直る。** AIで終わらせない

## 詰まったときの逃げ道

| 症状 | その場でやること |
|---|---|
| 動画が再生されない | 予備PCに切替。それも駄目なら演者が原稿を読み上げる |
| #4 の生成が返らない | 想定質問の保存音声を再生。なければ上記の逃げ台詞で #5 へ |
| 拍手が割れて判定できない | 「もう一度、Aの人だけ！」でやり直す。それでも微妙なら「割れました！」で正解発表 |
| ご本人が乗ってくれない | コメントを求めず、演者が「さすがですね！」で受けて次の問へ |
| 押している | 第5問を飛ばす／#4 を1問で切り上げる |
