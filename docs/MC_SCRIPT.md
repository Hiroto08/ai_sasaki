# 15分余興 実行台本（ステップバイステップ版）

**この1冊で当日を完走できる**ことを目指した台本です。
「**誰が**・**何を**・**どう操作するか**」を1手ずつ書いています。

- 役割は3名：**演者**（マイク／進行）・**PC**（映像と音の操作）・**サポート**（本人誘導・紙管理）
- 全体計画：[`EVENT_RUNDOWN.md`](EVENT_RUNDOWN.md)／外部サービス：[`SERVICE_SETUP.md`](SERVICE_SETUP.md)

**記号**：「 」＝そのまま読む台詞　／　`▸`＝ト書き（読まない）　／　`◆`＝アドリブ枠
　`▶ PC`＝PC担当の操作　／　`▶ サポート`＝サポート担当の動き

# 第0部　開演60分前〜直前

## S-1　機材セットアップ（開演60分前・PC担当）

1. ステージPCを会場のプロジェクタとPAに接続する
2. **音声出力がPA（会場スピーカー）になっている**ことを確認
   - 動画の音、フリー質問の音声、どちらもPAから出る必要がある
3. ブラウザで次の2つのタブを開いておく（**この順で左から**）
   - タブ1：`https://（アプリのURL）/qa.html` ← フリー質問用
   - タブ2：QRスライド（#5で使う）
4. 動画フォルダを開き、**再生順に並んでいる**ことを確認
   ```
   01_opening.mp4      #1 オープニング
   02_greeting.mp4     #2 AI挨拶
   03_q1_A.mp4 〜 07_q5_A.mp4   #3 クイズ5問
   08_loop.mp4         #4 ループ用
   ```
5. **予備PCにも同じフォルダがある**ことを確認する

## S-2　通し確認（開演40分前・PC担当）

6. **★オープニングのシンクロ確認**（[`OPENING_VIDEO.md` §5](OPENING_VIDEO.md)）
   - 音響担当と組んで、**音楽→動画の順**で1回通す
   - **22秒の「ワッショイ」と画面の大爆発が合うか**を必ず目視する
   - **動画の着地パターン（A / B / C）と全尺（30秒 or 33秒）を全員で共有する**
     → 演者の受けの長さが変わる（#1.5参照）。この日に決めて、当日変えない
   - `01_opening.mp4` を頭出しに戻す
7. `qa.html` を開き、合言葉を入力 → 画面右上が **「音声：接続OK」** になるか確認
   - 「未設定」と出たら音声機能は使えない。**文字読み上げ運用**に切り替える（S-10参照）
8. 想定質問5つを**すべて1回ずつクリック**して再生する
   → これで音声がキャッシュされ、**本番は即再生**になる（重要）
9. `08_loop.mp4` をループ再生して、違和感がないか確認

## S-3　紙の配置（開演30分前・サポート）

10. 演者に渡す：**この台本**／**設問5問と正解の紙**
11. PC担当に渡す：**再生順リスト**／**想定質問と回答の紙**
12. 予備として：**フリー質問の回答を印刷したもの**（音声が死んだ時に演者が読む）

## S-4　最終確認（開演10分前・全員）

13. 音響担当と**楽曲の再生キュー**を確認（#1で演者の合図と同時に流す）
14. ご本人に**#3で登壇いただくタイミング**を伝える（サポートが誘導）
15. PC担当は `01_opening.mp4` を**全画面・一時停止・頭出し**の状態で待機
16. タイマーを 00:00 で待機

## これだけは守る

1. **設問は紙のとおり読む。** 言い換えない
2. **動画中は喋らない。** 画面に集中させる
3. **#4で無音で待たない。** 「考えていますね」を必ず挟む
4. **8:50で第5問に入れなければ飛ばす。** 12:00で質問を打ち切る
5. **最後は必ずご本人に向き直る。** AIで終わらせない

## トラブル対応

| 症状 | その場でやること |
|---|---|
| 動画が再生されない | 予備PCに切替。それも駄目なら演者が原稿を読む |
| 音声が出ない | 画面の文字を演者が代読（S-10） |
| 生成が返ってこない | 想定質問の即再生に切り替える。なければ #5 へ |
| 拍手が割れて判定不能 | 「割れました！」と言って正解発表してよい |
| 本人が乗ってくれない | コメントを求めず「さすがですね！」で次の問へ |
| 押している | 第5問を飛ばす／#4を1問で切り上げる |
| 巻いている | #4の質問を3問に増やす／本人コメントを長めにもらう |
