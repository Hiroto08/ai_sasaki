# 15分余興 実行台本（ステップバイステップ版）

**この1冊で当日を完走できる**ことを目指した台本です。
「**誰が**・**何を**・**どう操作するか**」を1手ずつ書いています。

- 役割は3名：**演者**（マイク／進行）・**PC**（映像と音の操作）・**サポート**（本人誘導・紙管理）
- 全体計画：[`EVENT_RUNDOWN.md`](EVENT_RUNDOWN.md)／外部サービス：[`SERVICE_SETUP.md`](SERVICE_SETUP.md)

**記号**：「 」＝そのまま読む台詞　／　`▸`＝ト書き（読まない）　／　`◆`＝アドリブ枠
　`▶ PC`＝PC担当の操作　／　`▶ サポート`＝サポート担当の動き

---

# 第0部　開演60分前〜直前

## S-1　機材セットアップ（開演60分前・PC担当）

1. ステージPCを会場のプロジェクタとPAに接続する
2. **音声出力がPA（会場スピーカー）になっている**ことを確認
   - 動画の音、フリー質問の音声、どちらもPAから出る必要がある
3. ブラウザで次の2つのタブを開いておく（**この順で左から**）
   - タブ1：`https://（アプリのURL）/qa.html` ← フリー質問用
   - タブ2：QRスライド（#5で使う）
4. 動画フォルダを開き、**再生順に並んでいる**ことを確認
   ```
   01_opening.mp4          #1 オープニング
   02_greeting.mp4         #2 AI挨拶
   03_q1_reveal.mp4        #3 第1問 正解発表
   04_q2_reveal.mp4        #3 第2問 正解発表
   05_q3_reveal.mp4        #3 第3問 正解発表
   06_q4_reveal.mp4        #3 第4問 正解発表
   07_q5_reveal.mp4        #3 第5問 正解発表
   08_loop.mp4             #4 ループ用
   ```
5. **A/Bスライド5枚**を、動画とは別のウィンドウで開いておく（#3で使う）
   - スライドと動画を**交互に切り替える**ので、`Alt+Tab` の順番を体で覚えておく
6. **予備PCにも同じフォルダ・同じスライドがある**ことを確認する

## S-2　通し確認（開演40分前・PC担当）

7. **★オープニングを1回通し再生**（[`OPENING_VIDEO.md` §5](OPENING_VIDEO.md)）
   - **楽曲は動画に焼き込まれている**ので、再生ボタンひとつ。同期作業はありません
   - ★**PCの音が会場スピーカーから出ているか**を必ず確認（今回いちばん重要な確認）
   - **29.2秒の音のドロップと［歩きの到達＋青い大爆発］が合っているか**を目視する
   - **全尺 36.18秒**であることを全員で共有する
   - **後方席からテロップ「AI佐々木社長」が読めるか**を、実際に後ろまで歩いて確認
   - `01_opening.mp4` を頭出しに戻す
8. `qa.html` を開き、合言葉を入力 → 画面右上が **「音声：接続OK」** になるか確認
   - 「未設定」と出たら音声機能は使えない。**文字読み上げ運用**に切り替える（S-10参照）
9. 想定質問5つを**すべて1回ずつクリック**して再生する
   → これで音声がキャッシュされ、**本番は即再生**になる（重要）
10. `08_loop.mp4` をループ再生して、違和感がないか確認
11. **★A/Bスライドを1枚投影し、会場の後方まで歩いて文字が読めるか確認**する
    → 読めなければ文字を大きくする。**当日いちばん見落とされるのがここです**
12. **スライド → 正解発表動画** の切り替えを1問ぶん練習する（#3で5回繰り返す操作）

## S-3　紙の配置（開演30分前・サポート）

13. 演者に渡す：**この台本**／**設問5問と正解の紙**
14. PC担当に渡す：**再生順リスト**／**想定質問と回答の紙**／**A/Bの割り当て表**
15. 予備として：**フリー質問の回答を印刷したもの**（音声が死んだ時に演者が読む）

> 🚨 **A/Bの割り当て表（どちらがAIか）は、演者に渡さないでください。**
> 知っていると読み方に無意識の差が出ます。**PC担当だけが持つ**のが安全です。

## S-4　最終確認（開演10分前・全員）

16. **PCの音量を確定**（#1の動画から音が出ます。**音響担当の操作は不要**）
17. ご本人に**#3で登壇いただくタイミング**を伝える（サポートが誘導）
18. PC担当は `01_opening.mp4` を**全画面・一時停止・頭出し**の状態で待機
    - 🚨 **待機中に再生バーやマウスカーソルが映っていないか確認する**
      → 頭出し状態は黒フレームなので画面は黒いが、**コントロールが出ていると台無し**
    - **マウスを3秒動かさない**とコントロールは自動で消える。
      そのまま**キーボードのスペースキーで再生**する（マウスに触らない）
    - 💡 プロジェクタは完全な黒を出せず**うっすら光ります**（黒浮き）。
      これは機材の仕様なので気にしなくて構いません
19. タイマーを 00:00 で待機
