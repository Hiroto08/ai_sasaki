# AI社長アプリ（AI CEO Avatar App）

社長の口調・価値観・判断基準を再現した、アバター付きのAI社長と対話できるアプリケーション。

## このリポジトリについて

現在は **構築計画フェーズ** です。詳細な計画は以下を参照してください。

- 📋 [構築計画書（事例リサーチ・収集データ・アーキテクチャ・ロードマップ）](docs/PLAN.md)

## コンセプト

- 社員が社長に直接聞きづらい質問・相談・壁打ちをいつでもできる
- 経営理念・価値観・判断基準の浸透と継承
- 社長の口調・語尾・口癖まで再現した「本人らしさ」のある対話体験
- テキストチャット → 音声 → 動くアバター、と段階的に拡張

## 開発フェーズ（概要）

| フェーズ | 内容 | 目安 |
|---|---|---|
| Phase 0 | データ収集・整備（発言録、理念、Q&A収録） | 2〜4週間 |
| Phase 1 | テキストチャット版（ペルソナプロンプト + RAG） | 2〜3週間 |
| Phase 2 | 音声対応（音声クローンTTS） | 1〜2週間 |
| Phase 3 | アバター対応（静止画/リアルタイムアバター） | 2〜4週間 |
| Phase 4 | 精度改善・社内展開・運用 | 継続 |
